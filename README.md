\# Insurance Data Engineering Platform



\## Project Overview



A hands-on insurance data engineering project that processes fictional insurance data using AWS S3, Snowflake, dbt, SQL, and Python.



\## Architecture



Source Insurance Data → AWS S3 → Snowflake Bronze → dbt Silver → Gold Reporting Models



\## Data Domains



\- Policies

\- Policyholders

\- Claims

\- Agents

\- Payments



\## Engineering Goals



\- Reliable batch ingestion

\- Schema validation and controlled schema evolution

\- Data quality, reconciliation, and quarantine

\- Incremental processing and idempotency

\- Change Data Capture (CDC)

\- Slowly Changing Dimensions (SCD Type 1 and Type 2)

\- Dimensional modelling and reporting

\- Snowflake security and performance optimization

\- Monitoring, recovery, testing, and CI/CD



\## Development Approach



Begin with local development and fictional data. Introduce real AWS and Snowflake integration in later stages.



\## Project Status



Module 1: Repository and local Python environment setup in progress.
